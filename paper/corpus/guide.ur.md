# لیبل لگانے کی ہدایات

یہ [guide.md](guide.md) کا اردو ترجمہ ہے، لیبل لگانے والوں کی آسانی کے لیے۔ اگر دونوں میں کہیں فرق ہو تو انگریزی متن معتبر ہے۔

---

## صرف ایک سوال

آپ کو ایک ہی عبارت دو بار دکھائی جائے گی: ایک بار اس کی لائنیں دائیں سے شروع ہوں گی (دائیں سے بائیں)، اور ایک بار بائیں سے (بائیں سے دائیں)۔ ان دونوں میں اس کے علاوہ کوئی فرق نہیں۔

> **لکھنے والے کی مراد کے مطابق ان دونوں میں سے کون سی درست پڑھی جاتی ہے؟**

آپ سے یہ نہیں پوچھا جا رہا کہ عبارت کس زبان میں ہے، اس میں کتنے الفاظ کس زبان کے ہیں، یا کوئی program اس کے ساتھ کیا کرے گا۔ صرف یہ کہ اس عبارت کا پڑھنے والا کون سی شکل قبول کرے گا۔

## جواب

| بٹن | جواب | کب چنیں |
|---|---|---|
| 1 | **دائیں سے بائیں** | صرف دائیں سے بائیں والی شکل درست پڑھی جاتی ہے |
| 2 | **بائیں سے دائیں** | صرف بائیں سے دائیں والی شکل درست پڑھی جاتی ہے |
| 3 | **دونوں درست** | دونوں درست پڑھی جاتی ہیں، اور دونوں کا فرق پڑھنے والے کے لیے کوئی معنی نہیں رکھتا |
| 4 | **دونوں غلط** | دونوں شکلیں غلط ہیں: عبارت کے اندر کچھ نہ کچھ ترتیب سے ہٹ جاتا ہے، لائن جس طرف سے بھی چلے |
| 5 | **معلوم نہیں** | صرف اس عبارت کو دیکھ کر آپ فیصلہ نہیں کر سکتے |

## فیصلہ کیسے کریں

1. عبارت کو شروع سے آخر تک اس طرح پڑھیں جیسے اس کی اصل زبان کا پڑھنے والا پڑھتا ہے۔
2. دونوں شکلیں دیکھیں۔ درست شکل میں الفاظ اسی ترتیب میں آتے ہیں جس میں آپ پڑھتے ہیں، جملے کا فل سٹاپ اس کے آخر میں ہوتا ہے، اور list کا نشان یا لائن کا آغاز اسی طرف ہوتا ہے جہاں سے جملہ شروع ہوتا ہے۔
3. کسی دوسری زبان سے لیے گئے الفاظ جملے کی زبان نہیں بدلتے۔ `Debounce بمقابلہ Throttle` اردو کی سرخی ہے جس میں انگریزی کے دو اسم ہیں، اس لیے **دائیں سے بائیں**۔
4. کسی جملے میں ڈالا گیا ایک لفظ یا ٹکڑا بھی زبان نہیں بدلتا۔ *In Urdu this idea is called ایونٹ لوپ, but the mechanics are identical.* انگریزی جملہ ہے، اس لیے **بائیں سے دائیں**۔
5. فیصلہ سامنے موجود عبارت سے کریں۔ اگر صرف پورا جواب دیکھ کر ہی بات سمجھ آئے تو **معلوم نہیں** چنیں۔ آپ پورا جواب کھول کر بھی دیکھ سکتے ہیں، اور صفحہ یہ بات محفوظ کر لیتا ہے کہ آپ نے اسے کھولا تھا۔
6. یہ مت سوچیں کہ کسی program کو کیا کرنا چاہیے۔ اگر آپ کو محسوس ہو کہ آپ وہ جواب چن رہے ہیں جس سے کوئی اصول درست ثابت ہو، تو رکیں اور عبارت دوبارہ پڑھیں۔

**دونوں درست** بہت کم آئے گا۔ جس عبارت میں دونوں سمتوں کے حروف ہوں، اس کی دونوں شکلوں میں تقریباً ہمیشہ کچھ نہ کچھ ترتیب بدل جاتی ہے۔ یہ جواب تبھی چنیں جب یہ فرق پڑھنے والے کے لیے واقعی کوئی معنی نہ رکھتا ہو۔

آخری دو مثالیں بتاتی ہیں کہ صفحہ صرف وہی عبارتیں کیوں دکھاتا ہے جن میں کم از کم ایک اردو حرف اور ایک انگریزی حرف ہو: ایک ہی سمت کی عبارت پڑھنے کا ایک ہی طریقہ ہے، اور اس پر ہر اصول پہلے ہی متفق ہے۔

## صفحہ کیسے کھولیں

</div>

```
cd paper/corpus/tools
npm install
npm run label
```

<div dir="rtl">

`npm install` صرف پہلی بار چلانا ہے۔ پھر browser میں یہ پتا کھولیں: `http://127.0.0.1:4173/?by=owner`

دوسرا لیبل لگانے والا `by=` کے بعد اپنا نام لکھے، صرف چھوٹے انگریزی حروف میں، مثلاً `?by=ali`۔

**بٹن:** 1 دائیں سے بائیں، 2 بائیں سے دائیں، 3 دونوں درست، 4 دونوں غلط، 5 معلوم نہیں۔ **Backspace** سے پچھلی عبارت پر جائیں، اور **C** سے پورا جواب دیکھیں۔

یہ صفحہ صرف اسی کمپیوٹر پر چلتا ہے۔ ہر لیبل اسی وقت محفوظ ہو جاتا ہے۔

**چار امیدواروں والی فہرست (493 عبارتیں):** وہ عبارتیں جن پر Any RTL، ہمارا پہلا فارمولا، فائرفاکس 63 اور فائرفاکس 45 ایک جواب نہیں دیتے، Claude اور ChatGPT دونوں کے ڈیٹا سے۔ اسے یوں کھولیں:

</div>

```
cd paper/corpus/tools
npm run label -- --set four
```

<div dir="rtl">

پھر وہی پتا: `http://127.0.0.1:4173/?by=owner`۔ یہ لیبل الگ فائل میں رکھے جاتے ہیں (`private/labels/four`)۔ صفحہ یہ نہیں بتاتا کہ کون سا فارمولا کیا کہتا ہے، تاکہ فیصلہ صرف پڑھ کر ہو۔ کون سا فارمولا جیتا، یہ تبھی نکالا جائے گا جب ساری 493 عبارتوں پر لیبل لگ جائیں: `node score-four.mjs`۔

## کچھ ضروری باتیں

- وقفہ لیتے رہیں۔ ایک نشست زیادہ سے زیادہ 45 منٹ کی ہو۔ صفحہ خود بتا دے گا۔
- عبارتیں ایک مقررہ بے ترتیب ترتیب میں آتی ہیں، اور یہ نہیں دکھایا جاتا کہ کون سی عبارت کس جواب سے ہے۔
- جب تک لیبل منجمد نہ ہوں، آپ کوئی بھی لیبل بدل سکتے ہیں۔ منجمد ہونے کے بعد نہیں بدل سکتے۔
- ہر لیبل کے ساتھ یہ محفوظ ہوتا ہے کہ کس نے لگایا، کب لگایا، اور کیا پورا جواب کھولا گیا تھا۔
